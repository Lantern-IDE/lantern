# Lantern 이용약관 (초안)

시행일: [YYYY-MM-DD]
운영자: [상호 / 대표자 / 사업자등록번호 / 주소 / 통신판매업 신고번호(유료 판매 시)]

## 제1조 (목적)
이 약관은 [운영자](이하 "운영자")가 제공하는 코드 편집기 Lantern(이하 "앱")의 이용 조건을 정합니다.

## 제2조 (라이선스)
1. 앱의 공개 소스 부분은 [Apache License 2.0 — 확정 필요]에 따라 제공되며, 그 범위에서는 해당 라이선스가 이 약관보다 우선합니다.
2. 공개되지 않은 부분(유료 기능 등)은 운영자가 사용자에게 개인적·비독점적·양도 불가능한 사용권을 부여합니다. [범위 확정 필요]
3. 앱에 포함된 제3자 소프트웨어는 `THIRD_PARTY_NOTICES.md`에 적힌 각 라이선스를 따릅니다.

## 제3조 (AI 모델과 외부 서비스)
1. 앱은 AI 모델을 직접 제공하지 않습니다. 사용자가 고른 모델 제공자(Anthropic, OpenAI 등)나 로컬 모델을 호출하는 도구입니다.
2. 모델 제공자의 이용 요금, 약관, 사용 정책은 사용자와 해당 제공자 사이에 적용되며, 사용자는 자기 API 키로 발생한 요금을 부담합니다. 앱의 비용 미터와 한도는 추정치이며 실제 청구액과 다를 수 있습니다.
3. 사용자는 모델 제공자의 약관이 허용하는 범위에서만 앱을 사용해야 합니다.

## 제4조 (AI가 만든 결과물과 에이전트의 동작)
1. AI가 제안하거나 만든 코드와 설명은 틀리거나 안전하지 않을 수 있습니다. 결과물을 검토하고 적용할 책임은 사용자에게 있습니다.
2. 에이전트는 사용자가 승인하거나 설정에서 자동 승인하도록 허용한 범위에서 파일을 바꾸고 명령을 실행합니다. 자동 승인을 켠 경우 그 결과에 대한 책임은 사용자에게 있습니다.
3. 앱은 되돌리기(체크포인트)와 휴지통 삭제를 제공하지만, 모든 변경을 복구할 수 있다고 보장하지 않습니다. 중요한 프로젝트는 버전 관리(git)와 백업을 쓰기를 권합니다.
4. 신뢰하지 않은 폴더(제한 모드)에서는 프로젝트 설정, 훅, 쓰기·실행 도구가 꺼집니다. 사용자가 폴더를 신뢰하면 그 폴더의 설정과 명령이 실행될 수 있습니다.

## 제5조 (금지 행위)
사용자는 앱을 이용해 법령을 위반하거나, 타인의 권리를 침해하거나, 악성 코드를 만들거나 배포하는 행위를 해서는 안 됩니다.

## 제6조 (보증의 부인)
앱은 "있는 그대로" 제공되며, 법이 허용하는 범위에서 운영자는 상품성, 특정 목적 적합성, 무결성에 대한 어떠한 보증도 하지 않습니다. [소비자 관련 강행 법규와의 관계 검토 필요]

## 제7조 (책임의 제한)
운영자의 고의 또는 중대한 과실이 없는 한, 운영자는 앱 사용으로 생긴 데이터 손실, 모델 이용 요금, 간접 손해에 책임지지 않습니다. [유료 이용자에 대한 책임 한도 — 검토 필요]

## 제8조 (업데이트)
운영자는 앱을 개선하기 위해 업데이트를 제공할 수 있으며, 업데이트는 서명 검증을 거쳐 설치됩니다.

## 제9조 (약관 변경)
운영자는 관련 법령을 위반하지 않는 범위에서 약관을 바꿀 수 있으며, 시행 7일 전(사용자에게 불리한 변경은 30일 전)까지 알립니다.

## 제10조 (준거법과 관할)
이 약관은 대한민국 법을 따르며, 분쟁은 [관할 법원]을 제1심 관할 법원으로 합니다.
