## 1. 기본 원칙

Lantern(이하 "앱")은 사용자의 컴퓨터에서 동작하는 코드 편집기입니다. **운영자는 앱을 통해 사용자의 개인정보, 소스 코드, 대화 내용을 수집하거나 운영자의 서버로 전송하지 않습니다.** 앱에는 사용 통계(텔레메트리)나 광고 추적 기능이 없습니다.

## 2. 사용자의 컴퓨터에만 저장되는 정보

| 정보 | 저장 위치 | 목적 |
|---|---|---|
| 설정 (모델, 비용 한도, 단축키 등) | 사용자 폴더의 `.lantern/config.toml`, 앱 데이터 폴더 | 앱 동작 |
| AI 모델 API 키 | 운영체제의 자격 증명 저장소 (Windows 자격 증명 관리자 등) | 사용자가 고른 AI 서비스 호출 |
| 프로젝트 색인 (코드 심볼, 검색 색인) | 프로젝트의 `.lantern/index.db` | 프로젝트 맥락 검색 |
| 사용량·비용 기록 | 앱 데이터 폴더의 `usage.json` | 비용 미터 표시 |
| 신뢰한 폴더 목록 | 앱 데이터 폴더의 `trusted.json` | 제한 모드 판단 |
| 앱 로그, 충돌 보고서 | 앱 데이터 폴더의 `logs/` | 문제 진단. API 키처럼 보이는 값은 가려서 기록합니다 |

이 정보는 운영자에게 전송되지 않으며, 사용자가 언제든 해당 파일·폴더를 지워 삭제할 수 있습니다.

## 3. 사용자가 선택한 외부 서비스로 전송되는 정보

### 3.1 AI 모델 제공자
사용자가 AI 기능(채팅, 에이전트)을 사용하면, 앱은 **사용자가 설정한 모델 제공자**(예: Anthropic, OpenAI, OpenRouter, 또는 사용자 컴퓨터의 로컬 모델)에 직접 요청을 보냅니다. 요청에는 다음이 포함될 수 있습니다.

- 사용자가 입력한 메시지
- 질문과 관련해 앱이 고른 프로젝트 코드 일부 (앱 화면의 "Lantern이 본 코드"에서 무엇을 보냈는지 확인할 수 있습니다)
- 에이전트가 도구로 읽은 파일 내용과 명령 실행 결과

앱은 보내기 전에 API 키, 비밀번호, 개인 키처럼 보이는 값을 가리지만, 모든 민감 정보를 완벽히 찾아낸다고 보장하지는 않습니다. 이 전송은 운영자를 거치지 않으며, 전송된 정보의 처리는 **해당 모델 제공자의 약관과 개인정보 처리방침**을 따릅니다. 로컬 모델을 쓰면 정보가 컴퓨터 밖으로 나가지 않습니다.

### 3.2 업데이트 확인
앱은 새 버전이 있는지 확인하기 위해 하루 한 번 업데이트 서버([주소])에 접속합니다. 이때 앱 버전, 운영체제 종류, CPU 종류가 주소에 포함되며, 서버는 일반적인 웹 서버처럼 접속 IP 주소를 기록할 수 있습니다. [업데이트 서버 로그 보관 기간과 목적을 적으세요.]

### 3.3 언어 서버 설치
사용자가 언어 서버 설치에 동의하면, 앱은 npm 레지스트리(registry.npmjs.org) 또는 rustup 배포 서버에서 해당 도구를 내려받습니다. 이때의 정보 처리는 각 서비스의 방침을 따릅니다.
